# bridgemarket-eval-demo

강의 「LLM 평가와 안전 실전」 보너스 2(Promptfoo) 시연 저장소입니다. 가상 쇼핑몰 '브릿지마켓'의 가상 데이터만 들어 있습니다.

- PR을 열면 `.github/workflows/eval-gate.yml`이 후보 응답(`practice/s09_tools/promptfoo/ci/candidates.json`)을 섹션 2의 채점 기준("옛 정책을 현행처럼 안내했는가")으로 검사합니다.
- 모델을 부르지 않습니다. 저장된 답으로 검사 자체가 제대로 작동하는지 확인하는 단계입니다. 모델이나 검색 로직을 바꿨다면, 바뀐 앱에서 답을 새로 받아 이 파일에 넣고 같은 기준으로 평가합니다.
- 열려 있는 PR 두 개는 시연용입니다. 하나는 현행 정책으로 답한 후보(통과), 다른 하나는 1강 실행 기록 13번의 실패 답을 재현한 후보(실패)입니다.
- 병합을 실제로 막으려면 브랜치 보호 규칙에서 `eval-gate / old-policy` 검사를 필수 상태 검사로 지정합니다.

도구 버전(2026-11-20 확인): Promptfoo 0.125.1, Node.js 22, Python 3.12.
